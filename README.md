# PC SOLUTIONS — Servicio Técnico de Computadoras

Proyecto web básico creado con HTML, CSS y JavaScript.

## Cómo abrirlo
1. Descomprime la carpeta.
2. Abre la carpeta `servicio-tecnico` en Visual Studio Code.
3. Abre `index.html` en el navegador o utiliza la extensión Live Server.

## Personalización
Reemplaza el correo y teléfono de ejemplo en `index.html` por tus datos reales.

## Publicación
Puedes subir estos archivos a un repositorio de GitHub y activar GitHub Pages desde Settings → Pages.
